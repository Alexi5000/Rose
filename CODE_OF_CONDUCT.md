# Code of Conduct

Rose welcomes contributors who want to build safe, thoughtful, and high-quality AI companion software. We expect every participant to communicate with respect and care.

## Our standards

Contributors should use welcoming language, accept constructive feedback, focus critique on ideas and code, and respect the sensitivity of grief, wellness, voice, and memory features.

Unacceptable behavior includes harassment, discriminatory remarks, threats, doxxing, sexualized language, sharing private data without consent, or pressuring maintainers to disclose secrets, user data, or private deployment details.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, and other contributions that violate this code. Serious or repeated violations may result in temporary or permanent restrictions from project spaces.

## Reporting

If you observe unacceptable behavior, contact the repository owner privately through GitHub. Include relevant links, screenshots, and context where possible, but do not share private user data or credentials.
